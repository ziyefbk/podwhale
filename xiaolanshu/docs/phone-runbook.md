# 让手机零输入用上小蓝书：三条路的实际流程

> 目标：打开就是登录态，不用输令牌、不用扫配对码。
> 结论先行：**最小可行主体是个体工商户（营业执照）**。个人主体三条路都走不通。

## 0. 先看这张表，再决定走哪条

| 渠道 | 个人主体 | 企业/个体户 | 零输入登录 | 能主动推送 | 费用 | 大概周期 |
|---|---|---|---|---|---|---|
| 公众号（服务号） | ❌ 网页授权仅认证服务号 | ✅ | ✅ | ❌ 只能被动回复 | 认证 300/年 | 3–5 周（含备案） |
| **企业微信自建应用** | ❌ 需企业主体 | ✅ | ✅ | ✅ **应用消息** | **免费** | 2–4 周（含备案） |
| 小程序 | ❌ **UGC/社交类目个人不开放** | ✅ | ✅ | ⚠️ 订阅消息（要用户点授权） | 认证 300/年 | 3–6 周（含审核） |

依据：
- 网页授权「仅支持已认证的服务号」——[微信开放文档](https://developers.weixin.qq.com/doc/service/guide/h5/auth)
- 个人主体未开放「社交-笔记/社区论坛」类目——[官方社区回复](https://developers.weixin.qq.com/community/minihome/doc/0002284ca4883041feb40140c6b400)
- 小程序域名「不能使用 IP」「必须 ICP 备案」——[官方文档](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)

**建议：企业微信。** 免费、能主动推送（阿蓝答完直接弹消息）、审核比小程序松。

---

## 阶段 1：办主体（你）· 1–3 天

- [ ] 办个体工商户营业执照（各地政务 App / 一窗通办，多数免费或几十元）
  - 经营范围建议含：技术服务、软件开发、信息技术咨询
- [ ] 有执照后，注册**企业微信**组织（免费）或**微信服务号**（需认证 300/年）

产出：营业执照 + 统一社会信用代码。

## 阶段 2：域名 + 备案（你）· 2–3 周

- [ ] 买一个域名（腾讯云/阿里云，几十元/年）
- [ ] 买一台该厂商的国内轻量服务器（备案要求接入商，≥3 个月）——或者把现有服务器迁到该厂商
- [ ] 提交 **ICP 备案**（个人转企业主体备案；7–20 个工作日）
- [ ] 备案通过后 30 天内做**公安备案**（全国互联网安全管理服务平台）

产出：备案号 + 可解析的域名。

> 注意：现有 `https://xiaolanshu.example.com` 是 IP，**微信三个渠道都不接受**，必须换域名。

## 阶段 3：开通渠道（你）· 半天

**企业微信路线**
- [ ] 企业微信后台 → 应用管理 → 自建 → 创建应用
- [ ] 记录 `CorpID`、应用 `AgentId`、`Secret`
- [ ] 应用主页填 `https://<你的域名>/xiaolanshu/m`
- [ ] 可信域名填同一个域名，按提示上传校验文件
- [ ] 可见范围选自己（先自己用）

**服务号路线**（可选）
- [ ] 认证服务号 → 设置与开发 → 基本配置，记 `AppID` / `AppSecret`
- [ ] 网页授权域名填 `<你的域名>`
- [ ] 服务器配置：URL `https://<域名>/xiaolanshu/wechat`，Token 用 `XLB_WECHAT_TOKEN`

## 阶段 4：我这边配置 · 半天

- [ ] Caddy 加域名 + 自动证书（现有 `/xiaolanshu/*` 反代不动）
- [ ] 写环境变量并重启服务：

```bash
XLB_PUBLIC_URL=https://<你的域名>/xiaolanshu
XLB_WECHAT_APPID=<AppID 或 CorpID>
XLB_WECHAT_SECRET=<AppSecret>
# 走公众号时另加
XLB_WECHAT_TOKEN=<随机串>
XLB_WECHAT_OWNER=<你的 ownerId>
```

- [ ] 小程序路线：把 `xiaolanshu/miniprogram/utils/api.js` 里的 `BASE` 换成 `<域名>/xiaolanshu`，`project.config.json` 的 `appid` 换成你的

## 阶段 5：联调（我 + 你）· 1 天

- [ ] 手机在企业微信里点开应用主页 → 应直接进 `/m`，无需输入
- [ ] 检查 `/health` 与 `status.mjs`
- [ ] 发一条帖、提一个问题，确认落库
- [ ] 触发一次巡检，确认能**主动推送**到企业微信（这是选企微的主要理由）

## 阶段 6：小程序（只有需要时才做）

代码已经写好（`xiaolanshu/miniprogram/`，4 个页面 + 静默登录），但：
- [ ] 必须在**企业/个体户**主体下注册，个人主体选不到社区类目
- [ ] 提审时需要提供内容审核机制说明、举报入口、用户协议
- [ ] `web-view` 不可用，页面是重写的，不是嵌 `/m`

## 费用小结（第一年）

| 项 | 费用 |
|---|---|
| 个体工商户 | 0–100 元 |
| 域名 | 50–100 元 |
| 国内服务器（备案要求） | 100–300 元（或复用现有机器，需迁到有备案资质的厂商） |
| 企业微信 | 0 |
| 服务号认证（如走服务号） | 300 元 |
| 小程序认证（如走小程序） | 300 元 |

**最省组合：个体户 + 域名备案 + 企业微信 ≈ 200 元级。**

## 风险提示

1. **审核类目**：无论哪个渠道，UGC 社区都可能被要求补充「社交」类目与资质；企业微信自建应用内部使用审核最松，对外发布最严。
2. **备案周期不可控**，7–20 个工作日，遇节假日更久。
3. **不要在过渡期用 IP 硬上**：小程序的域名校验、服务号的网页授权域名都不接受 IP。
4. 现在的配对码方案（6 位数字）是**不依赖任何主体**的可用方案，可以先一直用着。
