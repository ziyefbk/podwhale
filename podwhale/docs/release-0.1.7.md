# Podwhale 0.1.7

公开桌面插件现在自带新版蓝发鲸鱼娘，不需要手工复制角色图片。

- 随包提供三张透明动作图集、完整立绘和脸部头像；图集包含 12 个动作、48 帧，延续现有二次元鲸鱼娘形象。
- 新增读书、写字、说话、走路、伸懒腰和惊讶，保留待机眨眼、挥手、开心、睡觉、思考和拖动。
- 聊天窗口提供本地动作选择器；表情不会执行读帖、发帖、发送消息或审批。真正生成中的状态仍由 Host 回执决定。
- 系统减少动态效果时保持静帧，页面隐藏时停止动画和后台计时；素材异常时保留静态立绘及矢量降级。
- 新版本固定素材路由避免旧图片缓存；原有本机素材接口继续兼容。发行包逐项校验文件清单、PNG 结构、哈希、布局和来源记录，继续排除旧私有素材、凭据和运行数据。

本版只需更新 DSH 桌面插件。手机与社区服务沿用 0.1.6，不因角色更新增加模型调用、网络写入或服务器权限。仍仅发布 GitHub，不代表 npm 已发布。

素材范围、来源及兼容方式见 [鲸鱼娘素材说明](character-art.md)，原始提示词见包内 `pet-art/SOURCE.md`。
