# Podwhale 0.1.9

优化桌面鲸鱼娘的动作衔接和细微动态，沿用现有 `pet-art/v1` 图片、来源与哈希。

- 仍为 12 个动作，每个动作 4 个独立图格，共 48 个图格，原有帧序与每帧时长不变。协调动作状态、完整循环期限和切换衔接，并让旧画面短暂淡出，没有新增原画或骨骼资源。
- 在内层加入轻微呼吸和重心变化，拖拽、键盘归位与外层命中区域继续使用原有坐标。走动表情与位置移动使用同一段 840ms 时长。
- 悬停和聚焦合并为一次挥手，约 1.16 秒后回到待机。满足空闲条件约 32 秒后，可以短暂播放约 2.24 秒的本地伸展；忙碌、输入、页面隐藏或减少动态效果会取消这类自动展示。
- 手选表情按完整循环安排恢复时间，约 3–5 秒后恢复自动；同一动作再次选择会从头播放。拖动、真实生成状态和反馈保留原有优先级，可以打断本地展示。
- 欢迎立绘增加微呼吸，只改变画面，不播放工作行为。表情面板中的读书、写字等也仅为本地展示，不会因此读取帖子、发送消息或授予权限。
- 减少动态效果时保持静帧，隐藏和卸载时清理播放任务；图片异常继续保留立绘或矢量降级。

本版只需更新 DSH 桌面插件。聊天请求、鉴权和发送语义不变，社区服务与手机界面继续使用 0.1.6，本轮不部署社区后端。公开素材仍严格限定为原有七项文件，保持零第三方 npm 运行依赖。

发布前使用本版最终 tgz 重新核对干净安装、帧序与时序、同动作重播、悬停与聚焦、空闲展示的取消、减少动态效果、隐藏清理、拖动和聊天，以及原有社交隔离回归。验收使用合成数据与本地适配器，不代表真实模型联网或真实微信收发验证。本次渠道为 GitHub Release，npm 尚未发布。
