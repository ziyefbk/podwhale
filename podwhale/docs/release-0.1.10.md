# Podwhale 0.1.10

增加本插件的动画模式选择，并将社交设置整合进鲸群内页。方便在系统关闭动画时显式选择是否播放鲸鱼娘动作，默认仍跟随系统，不修改 Windows 或其它应用的设置。

- **跟随系统**（默认）：遵守系统的减少动态效果偏好；系统要求减少动态时使用静帧。
- **播放动画**：由你显式选择，仅在本插件内覆盖系统减少动态偏好，播放原有动作与细微动态。
- **保持静止**：无论系统偏好如何，均保持静帧。

模式保存在当前客户端本地，可随时恢复跟随系统或静止。页面隐藏时三种模式都停止动画；播放模式不会越过隐藏清理，也不会把本地读书、写字表情变成真实工作。

侧栏统一使用鲸群入口，从社区进入“社交设置”，点击“返回鲸群”回到社区。“我的 AI”和聊天窗更多菜单的快捷入口也打开同一内页。在同一已打开插件中切页保留未保存的设置草稿，不会自动保存、启动巡检或提交授权申请。离开设置页不等于暂停阅读计划，需要停止时仍使用“暂停并停止本轮”。

继续使用原有 `pet-art/v1` 的十二动作，每动作四个独立图格。PNG、来源和哈希不变，没有新增原画、骨骼资源、第三方 npm 运行依赖、Host 接口或业务权限。动画偏好仅保存在客户端，页面沿用原有状态读取与显式操作。聊天发送、取消、清空、审批与社交授权边界保持原样。

本版只需更新 DSH 桌面插件，社区服务和手机界面仍为 0.1.6，本轮不部署社区后端。README 中的 0.1.9 动图保留其原版本来源，不作为 0.1.10 新界面截图。

发布前使用最终 tgz 重新验证离线干净安装、跟随系统/播放/静止的切换与本地保存、系统减少动态时的显式播放、隐藏后停止、原有动作和聊天交互，以及鲸群内页导航、草稿保留和社交隔离回归。测试使用独立临时 profile 和合成适配器，不代表真实模型或微信联网验证。本次发行渠道为 GitHub Release，npm 尚未发布。
