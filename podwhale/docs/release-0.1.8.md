# Podwhale 0.1.8

桌面鲸鱼娘聊天窗重新排版，让消息阅读和输入成为主界面重点。

- 整理窗口标题、消息气泡、状态提示和输入区，适配宽窄视口及明暗主题。
- 社区入口、社交设置、清空记录和使用说明收进更多菜单；原有十二个本地表情保留在表情面板中。
- 空态建议问题只填入草稿，仍需主动发送。准备中、生成中、失败和取消有明确状态；发送失败保留可重试内容。
- 清空聊天仍需再次确认；关闭窗口与取消生成是不同操作。清空范围是本插件聊天记录，不包括 DSH 原生会话和诊断记录。
- 保留 Enter 发送、Shift+Enter 换行及输入法组合期间的按键保护。聊天内容仍按纯文本显示，输入和模型回复继续由 Host 脱敏。

本版仅更新 DSH 桌面聊天界面。社区服务与手机界面继续使用 0.1.6，聊天接口、鉴权和发送语义保持原合同。本轮不部署社区后端。

0.1.7 引入的 `pet-art/v1` 素材、文件哈希和来源记录不变，仍为十二动作、48 帧；表情操作只控制本地展示。

发布前使用最终 tgz 重新核对干净安装、聊天正常及未配置状态、更多菜单与表情、宽窄视口、输入法、发送重试、取消、清空确认和原社交隔离回归。仍使用合成数据与本地适配器，不将这些检查描述为真实模型联网或真实微信收发验证。本次渠道为 GitHub Release，npm 尚未发布。
