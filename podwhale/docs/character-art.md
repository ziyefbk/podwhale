# 内置鲸鱼娘素材

从 0.1.7 开始，公开插件包包含新生成的鲸鱼娘头像和动作素材，安装后不需要另行复制本机私有图片。新素材使用项目公开宣传插画作为视觉参考，由内置 imagegen 工具生成；具体提示词、参考文件及生成记录见包内 `pet-art/SOURCE.md`。来源记录不等于第三方权利的授权证明，也不会将旧二创素材重新声明为 MIT 素材。

## 固定发行清单

只允许以下 7 个文件进入公开包，不能用通配符将整个素材目录打包：

| 文件 | 内容 |
| --- | --- |
| `pet-art/atlas-a.png` | 4 行 × 4 帧：idle、wave、happy、sleep |
| `pet-art/atlas-b.png` | 4 行 × 4 帧：think、drag、read、write |
| `pet-art/atlas-c.png` | 4 行 × 4 帧：talk、walk、stretch、surprised |
| `pet-art/portrait.png` | 透明背景头像 |
| `pet-art/face.png` | 透明背景脸部头像 |
| `pet-art/manifest.json` | 文件哈希、实际宽高、动作顺序与来源摘要 |
| `pet-art/SOURCE.md` | 生成提示词、参考图与来源说明 |

每张动作图有 16 个单元格，3 张图共 12 个动作、48 帧。按图片实际宽高除以 4 计算单元格；不要求像素尺寸能够被 4 整除，不能取整后累计偏移。

## 运行时与旧安装兼容

新客户端只使用固定的 `/xiaolanshu/pet-art/v1/` 路由及清单中的 5 个 PNG 文件名。这些路由只读取公开素材，不读取旧本地 `assets`，不接收任意路径或文件参数。只有 GET 和 HEAD 可用，图片响应带有 PNG 类型及 `nosniff`。

旧的 `/xiaolanshu/avatar.png`、`face.png`、`pet-actions-a.png`、`pet-actions-b.png` 保留原本地素材优先的兼容行为；只有对应旧文件不存在时才回退新素材。新增的 `pet-actions-c.png` 别名只映射公开 C 图。旧 B 图是 2 行，新 B 图是 4 行；客户端应校验布局，布局不兼容时使用静态头像，不能按旧行数错误裁切新图。

版本化公开 URL 可以长期缓存；替换已发布画面时应使用新版本路径，不能复用同一版本 URL 发布不同图像。旧别名继续短缓存。缺失素材返回无缓存的 404，客户端保留静态头像和矢量降级。

窄窗口宽度不超过 600px 且高度至少 740px 时，聊天窗下方留出角色展示区域。更矮的窗口优先保留聊天控件，角色可能位于聊天窗后方；可收起聊天或放大窗口观看。窗口布局不会改写已保存的拖拽坐标。

## 发行校验与边界

发行工具要求完整清单，并校验严格 manifest、来源文档哈希、每张 PNG 的 SHA-256、真实宽高、RGBA 通道、PNG 分块边界及 CRC。打包前和读取实际 tgz 后都执行校验。PNG 结构检查不等于完整像素解码；真实透明像素、帧边缘与动画裁切另外通过离线图片分析及原生界面验收确认。

`assets/*.png`、本机候选图、私有配置、聊天数据和数据库仍禁止进入公开包。`pet-art/` 下不在清单中的文件也会被发行校验拒绝，添加新公开素材必须同时更新固定清单、来源说明、manifest 和测试。
