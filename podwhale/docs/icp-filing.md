# 备案操作手册（个体户 → 域名 → 小程序/企微）

## 0. 先分清两个"备案"

它们不是一回事，做完一个不代表另一个也能上线。

| | **域名 ICP 备案** | **小程序备案** |
|---|---|---|
| 谁受理 | 省通信管理局（通过**服务器接入商**提交） | 微信公众平台代为提交 |
| 干什么用 | 让域名能在境内服务器上对外提供网页 | 让小程序能**上传代码、提交审核、发布** |
| 前提 | 已实名域名 + 该接入商的境内服务器 | 已注册的小程序 + 主体资料 |
| 个人能做吗 | 能（个人性质备案） | 能（个人小程序可备案，免费） |
| 周期 | 5–20 个工作日 | 平台初审 1–2 天 + 管局 |

> **注意**：个人能做"小程序备案"，不代表能做"社区类小程序"——后者卡在**服务类目审核**（UGC/社交个人不开放）。备案和类目是两道门，都要过。

---

## A. 域名 ICP 备案（你真正要走的那一步）

### 前提（缺一不可）

- [ ] 域名已**实名认证**，且持有者名称 = 营业执照上的名称（个体工商户就是执照上的字号）
- [ ] 域名在**境内有资质的注册商**买的（腾讯云/阿里云/新网等）
- [ ] 一台**该接入商**的境内服务器，通常要求包月 ≥3 个月（备案要绑定接入商，跨厂商不行）
- [ ] 网站还没对外开：**未备案的网站不能打开**，备案期间保持关闭或用二级域名占位

### 材料清单（个体工商户按"企业"备案）

| 材料 | 说明 |
|---|---|
| 营业执照 | 原件彩色扫描/拍照，四角齐全、无遮挡 |
| 法人身份证 | 正反面 |
| 法人手机号 | 必须能接到管局回访电话 |
| 应急手机号 | 不能与法人手机号相同 |
| 邮箱 | 常用、能收验证码 |
| 网站负责人 | 可与法人同一人；不同人需额外身份证 + 授权 |
| 手持身份证照片 | 部分省要求，背景干净、五官清晰 |
| 域名证书 | 在域名控制台下载 |
| 《网站备案信息真实性核验单》 | 系统内生成，打印签字/盖章后上传 |

### 步骤

1. **登录接入商后台**（如腾讯云 → 网站备案），选「企业备案」，主体类型填**个体工商户**
2. 填主体信息：名称、统一社会信用代码、注册地址（**必须与执照逐字一致**，含括号全半角）
3. 填网站信息：网站名称（别用"论坛""社区"这类词）、域名、服务内容
4. 上传材料 + 人脸核验（法人本人扫码）
5. **接入商初审**：1–3 个工作日，驳回会短信通知补材料
6. **管局审核**：5–20 个工作日（各省不同，可查排队）
7. 下发**备案号**（形如 `京ICP备2026xxxxxx号-1`）
8. 把备案号放在网页底部，并链接到 `https://beian.miit.gov.cn`

### 费用与时间

- 备案本身**免费**（接入商不收费）
- 真实成本是"必须买该厂商的服务器"
- 总体 2–4 周，跨节假日更久

### 常见被驳回的原因

- 主办单位名称与执照不完全一致（多一个空格、"有限公司"简写成"公司"）
- 网站名称含敏感词（论坛、社区、直播）
- 域名持有者与主体名称不一致
- 手机号已在别的备案里用过且未注销
- 网站内容与备案填写的服务内容不符（备案期间网站最好别开）
- 材料照片模糊、遮挡、有反光

## B. 小程序备案（如果最终走小程序）

在**微信公众平台**里做，不在工信部系统。

**材料**：营业执照、法人身份证正反面、小程序管理员身份证、人脸核验（法人或管理员扫码）

**步骤**
1. 登录 mp.weixin.qq.com → 首页「去备案」（已上架的：设置 → 小程序备案）
2. 填主体信息（地区选执照所在地，逐字对照执照）
3. 填小程序信息：服务内容标识 1–2 个、前置审批选"以上都不涉及"
4. **备注必填，且很关键**（20–200 字），写实际服务内容，模板：

   > 本主体为【执照名称】，本次备案的小程序【小程序名称】主要服务内容为：【具体描述，例如"提供 AI 社区内容的浏览与发布"】。承诺不涉及新闻、时政等前置审批内容。

5. 提交 → 平台初审 1–2 个工作日 → 管局
6. 备案完成后才能上传代码、提审、发布

**易错点**
- 管理员**不能与主体负责人同一个人**（部分省份规则，按后台提示为准）
- 应急手机号不能与法人、管理员手机号相同
- 备案通过后工信部查询有 1–7 天同步延迟，不是失败

---

## C. 公安备案（ICP 通过后 30 日内）

- 平台：全国互联网安全管理服务平台
- 时间：约 10 个工作日
- 材料：主体证件、负责人身份证、域名证书、网站信息
- 通过后把公安备案号也放页面底部

---

## D. 备案之后

- [ ] 网页底部放备案号 + 链接工信部
- [ ] 30 日内做公安备案
- [ ] 域名解析到服务器，配 HTTPS 证书
- [ ] 小程序/企微后台把域名加到白名单（小程序的「服务器域名」、企微的「可信域名」）

---

## E. 你这套东西的对应关系

```
域名 podwhale.example.com
  └─ ICP 备案（阶段 A，个体户）        ← 现在卡在这
      └─ 解析到 <你的服务器> + 证书   ← 我配 Caddy
          ├─ 小程序「服务器域名」白名单  ← 小程序路线
          └─ 企微「可信域名」校验文件    ← 企微路线
```

**没有备案域名，微信三个渠道都无法在真机上请求你的服务**——开发阶段只能在开发者工具里勾「不校验合法域名」自测。

---

## 时间预算（保守）

| 步骤 | 时间 |
|---|---|
| 办个体户执照 | 1–3 天 |
| 买域名 + 实名 | 1 天（实名审核 ~1 天） |
| 买境内服务器 | 当天 |
| ICP 备案（含初审） | 2–4 周 |
| 公安备案 | ~10 个工作日（可与后续并行） |
| 小程序备案 | 1–3 周 |
| 小程序提审 | 1–7 天 |

**最短可上线路径：先只做 ICP 备案 → 配域名证书 → 用企业微信自建应用（免小程序审核）。**
