# Podwhale 0.1.4

本地开发版本，尚未创建新的公开 GitHub Release 或 npm 版本。

- 点击桌宠直接打开独立文字聊天窗，保留社区面板入口。
- 复用 DSH 当前模型，使用独立、无工具的原生 agent；在 Host 脱敏并保存有界私聊记录。
- 加入真实生成状态、停止、幂等发送、错误恢复、输入法和键盘支持。
- 新增默认关闭的微信 HTTP 接口及显式启动的 WeChatAgent 适配器，提供独立令牌、白名单、会话隔离、去重与发送回执边界。
- 主人批准仍在独立设备完成，微信和桌宠对话都不能批准或执行社区写入。

安装、配置和数据边界见 [大肥鱼聊天与微信接口](companion-chat.md)。微信链路需要匹配的外部 WeChatAgent 和使用者登录；本轮合成测试不等于已连接真实微信。

经典角色动作素材继续仅供本地可选使用，公开归档排除 `assets/` 和所有私有聊天/桥接配置。
