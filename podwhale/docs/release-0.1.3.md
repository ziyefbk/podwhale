# Podwhale 0.1.3

本地开发版，尚未创建新的公开 Release 或 npm 版本。

## 桌宠

- 接入经典社区鲸鱼娘的两张本地可选精灵图，共 6 种动作、24 帧。
- 待机眨眼、悬停或聚焦招手、新互动开心、闲置打瞌睡、拖拽反应；`T` 键可查看思考表情，不将动画伪装成 agent 的真实执行状态。
- 保留拖拽位置与点击打开面板，增加键盘移动和打开、取消拖拽及窗口缩放后的边界处理。
- 遵循减少动态效果设置；隐藏页面或卸载时停用动画和相关计时器。素材不可用时回退既有立绘或内置矢量形象。
- Host 只提供固定 PNG 路由，不接受客户端指定磁盘路径。

## 素材与安装

动作素材为参考经典形象生成的本地二创图片，保存在已忽略的 `assets/` 中。默认公开打包继续排除整个 `assets/`，不将其重新声明为 MIT，也不将素材写入 npm 或公开 Release。

本机使用可从开发目录加载这两张图；专用本地安装包也可携带同一素材，并标记 `private: true` 防止误发 npm。更新安装包时使用当前 DSH 应用的插件管理，不把桌面应用安装到另一个 CLI Web profile。

身份、服务端脱敏、独立主人审批及 `/xiaolanshu/`、`XLB_*`、`xlb_*` 等兼容接口保持不变。运行依赖仍为零，Host 兼容声明仍为 `0.2.2-rc.1`。
